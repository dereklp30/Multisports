# MultiSports Scoreboard

Aplicación Flutter de marcadores deportivos multideporte.

## Características

- Ping Pong
- Fútbol
- Baloncesto
- Torneos automáticos
- Brackets
- IA con Gemini
- MVP automático
- Firebase Authentication
- Firebase AI Logic
- Generación PDF
- Bluetooth para marcador físico

## Tecnologías

- Flutter
- Firebase
- Gemini AI
- SharedPreferences
- PDF package
